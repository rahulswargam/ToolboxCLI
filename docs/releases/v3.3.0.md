# Rahul's Toolbox v3.3.0

Native Windows toolbox for PDF, image and file tasks, with a monochrome
dashboard, Dark / Light / Auto themes and local processing.

## Included

- Sixteen tools, including PDF merging, compression, signing, rotation,
  page organization and removal, image conversion, and duplicate-file cleanup.
- Direct PDF form filling: click detected blanks and type, with grouped
  character cells, Tab navigation, date paste support, leading-zero retention
  and editable PDF export. Local OCR assists scanned-page recognition.
- Full-page previews, zoom, maximizable tool dialogs, draggable and resizable
  signatures, and undo / redo.
- Corrected favorite interactions, whole-card tool launching, alignment,
  installer header artwork and installed shortcut branding.
- Windows setup bundles Python and runtime dependencies, with Start menu
  integration, an optional desktop shortcut and an uninstaller.

## Downloads

- `RahulsToolbox-3.3.0-Setup.exe`: Windows 10 (1809+) / 11, 64-bit.
- `RahulsToolbox-3.3.0-Source.zip`: application source and build scripts.
- `SHA256SUMS.txt`: checksums for both files.

Run setup and follow the wizard. No separate Python installation is required.
Builds are unsigned. See `THIRD_PARTY_NOTICES.md` for component licenses.

## Validation and limits

The release passed 82 automated tests, including regression checks against
the public HDFC form reported during development. Separate installer checks
verified installation, the branded shortcut, packaged tool behavior and
uninstallation. The public bank template and private documents are excluded
from the release.

Field recognition depends on layout and scan quality; review the result and
use manual tools for missed blanks. Signatures are visual marks, rather than
certificate-based digital signatures. Existing PDFs are preserved by saving
edited documents to new files.
